Initial Ideation

As an MSP Admin, I would like to monitor my workload from the Druva console for MSSP customers. Scope = MSP Admin

MSP Admin
Enter Customer console
Launch Druva Control Panel
Access health & diagnostics
Perform Tasks
Commit / Close Session

As an MSP Admin, I would like to quickly switch between different Druva customer tenants. Scope = MSP Admin

MSP Admin
Enter Customer console
Select customer from dropdown list
Switch context
Perform tasks / monitor
Success Notification

As the MSP Partner, I should be able to view an overarching usage dashboard for MSP customers. Scope = MSP Admin, MSP STSC etc

As an MSP Admin, I should be able to grant access to existing Druva users in customer consoles. Scope = MSP Admin

MSP Admin
Enter customer context
Select customer
Share data with agent
Perform Tasks
Commit / close session
Change login for the relevant tenants

As an MSP Admin, I should be able to create new Druva entities within customer consoles. Scope = MSP Admin

MSP Admin
Enter customer context
Select customer
Create new tenant
Perform Tasks
Success Notification
Change context for the relevant tenants

As an MSP Admin, I should be able to Request Products.

MSP Admin
Enter Customer Console
Browse & Select an MSP client
Request Products
Fill Product request / Details / PO
Perform Tasks
Success Notification

As a Druva Admin, I should be able to assist customers via the console with scoped access.

MSP Admin
Enter Customer Console
Select Customer tenant
Edit customer / service details
Confirm Details
Accept terms
Success Notification
  • The product request workflow starts from Druva console and ends at MSP console.
  • Only admin of owner should be granted authorization to delete other users.
  • Should link to SSO to help customers enter with an MSP specific API integration.
  • Druva Admin can control the product requests for the assigned customer.

As a user (MSP Admin), I should be able to create and update Druva users in customer consoles. Scope = MSP Admin, MSP STSC etc.
