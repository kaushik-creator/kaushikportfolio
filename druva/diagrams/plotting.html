Plotting Who, What, When, Where and How?

Users

  • MSP Admin
  • Druva SE Team
  • MSP Customer DCP Admin

Customer Type

  • MSC — Direct MSC Tenant
  • Elite — MSC Tenant for selling products
  • Organic — Direct DCP Tenant

Managed Type

Managed Customer: MSP Admin will have direct access to customer tenant Console.

Un-Managed Customer: MSP Admin will not have direct access to customer tenant Console.

Use Cases — MSP Admin

  • Creating a New Tenant as a Discrete Tenant
  • Request for products for a certain time for adding product license
  • Marking a managed tenant as a Unmanaged Tenant
  • Requesting View access for a certain time
  • Requesting Unmanaged tenant on a managed tenant

Use Cases — Druva SE Team

  • Allocating the Tenant to certain implementation
  • Converting the organic tenant to a discrete tenant
  • Convert unmanaged tenant to managed tenant
  • View access for a certain time

Use Cases — MSP customer DCP Admin

  • Allowing the MSP admin access the console for a certain time

Creating a New Tenant as a Discrete Tenant

User: MSP Admin · Console: MSC

Step 1: Create a tenant

Step 2: Fill details like tenant name, Email ID, Status: New/Evaluation etc.

Will be reflected in the MSP Customer listing page.

Marking an organic tenant to a discrete tenant

User: SE Team · Console: Druva Central

Step 1: Search the tenant

Step 2: Mark as Discrete Tenant

Step 3: Map MSP

Step 4: Add confirmation

Will be reflected in the MSP Customer listing page.

Adding products

User: MSP Admin · Console: MSC

Step 1: Customer list page

Step 2: Request for products alone with User count etc.

It should wait for the SE team approval

Marking a tenant as a Unmanaged Tenant

User: MSP Admin · Console: MSC

Step 1: Customer info page

Step 2: Mark as Unmanaged Tenant (this will remove view access from this)

Will be reflected in the MSP Customer listing page.

Requesting Unmanaged tenant on a managed tenant

User: MSP Admin · Console: MSC

Step 1: Customer info page

Step 2: Request to be part to (set to unmanaged)

Will be reflected in the MSP Customer listing page.

Requesting view access for a certain time

User: MSP Admin · Console: MSC

Step 1: Customer info page

Step 2: Request for access for a certain time

It should wait for the customer approval

Allowing the DCP admin access the console for a certain time

User: DCP Admin · Console: Druva Cloud Platform

Step 1: Notification

Step 2: Approve / reject request

It should wait for the customer approval
