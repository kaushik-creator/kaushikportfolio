Personal Project

Dashboard

A personal learning project focused on designing a dashboard that helps users consume information quickly and clearly.

This exploration uses a drone fleet management template — fleet status, live telemetry, mission planning, and alert triage — to practice information density, visual hierarchy, and scannable layout without decorative chrome. Each screen in the carousel tests a different slice of that problem: how much data belongs above the fold, how severity reads at a glance, and how navigation stays stable when the underlying metrics change.
